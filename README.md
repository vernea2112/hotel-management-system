# Hotel Management System (HMS)

## English

A comprehensive Hotel Management System built with Laravel and PHP. This system provides tools for managing hotel operations including guests, rooms, reservations, billing, and staff management.

### Features
- Guest Management
- Room Management
- Reservation/Booking System
- Check-in/Check-out
- Billing and Payment Processing
- Staff Management
- Reports and Analytics
- Multi-language Support (English & Portuguese)

### Requirements
- PHP 8.1+
- Composer
- MySQL/MariaDB
- Laravel 10.0+

### Installation

```bash
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate
php artisan serve
```

### Usage

The system will be available at `http://localhost:8000`
